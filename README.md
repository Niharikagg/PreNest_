# PreNest

PreNest is a Flutter Android application designed to help couples preparing for pregnancy organize and understand their health-report information.

## Core Flow

```text
Report Image
     ↓
Image Quality & Correction
     ↓
OCR / Extraction
     ↓
User Verification
     ↓
Verified Data
     ↓
Safe Comparison & Trends
     ↓
Charts / Summary
```

## Important

PreNest is an informational application.

It does not diagnose medical conditions or prescribe treatment.

## Project Structure

- `lib/features/` — application features
- `lib/core/` — shared infrastructure and contracts
- `assets/` — application resources
- `eval/` — synthetic evaluation data
- `test/` — automated tests
- `docs/` — project documentation
